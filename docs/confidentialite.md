# Politique de confidentialité — FootCoach

*Brouillon, à publier sur une page web publique (par ex. GitHub Pages) puis à renseigner dans Play Console.
Dernière mise à jour : 4 novembre 2026.*

**FootCoach** est une application d'organisation d'entraînements de football. Cette politique explique quelles
données elle traite.

## Données traitées
Vous saisissez dans l'application : équipes, joueurs (nom, prénom, date de naissance, poste, numéro,
téléphone, adresse e-mail, remarques éventuelles), séances d'entraînement, présences et schémas tactiques.

## Où sont-elles stockées ?
Uniquement **sur votre appareil**, dans le stockage privé de l'application (base SQLite). L'éditeur de
l'application ne reçoit, ne collecte et ne consulte aucune de ces données.

## Partage et collecte
- L'application n'utilise Internet que pour une seule chose : envoyer un signalement d'assistance, **uniquement lorsque vous touchez « Envoyer le signalement »** (voir « Assistance » ci-dessous). Aucune autre donnée n'est transmise, et rien n'est envoyé en arrière-plan.
- Aucune publicité, aucun outil de mesure d'audience, aucun service tiers.
- Une seule permission Android : « Internet », nécessaire à cet envoi. Aucun accès aux contacts, à la position, aux photos, au micro ni à l'appareil photo.

## Export et import volontaires
La page « Données » permet de créer un fichier contenant toutes vos données, que vous envoyez vous-même (par exemple
par WhatsApp ou e-mail) à un autre de vos appareils. Ce transfert est initié par vous, passe par l'application de votre
choix et n'implique aucun serveur de l'éditeur de FootCoach. L'application elle-même n'envoie rien. Le fichier contient
les noms, dates de naissance, téléphones et adresses e-mail saisis : traitez-le comme vos données d'origine.

## Assistance (signalement, e-mail)
Le menu « Paramètres » permet de signaler un problème, de proposer une amélioration ou de contacter le support. Si vous
touchez « Envoyer le signalement », l'application crée un ticket sur le dépôt public de FootCoach sur GitHub (titre « SUP - … »,
description, et la version de l'application et le système si vous le choisissez). Aucun compte GitHub n'est nécessaire et
rien n'est envoyé avant ce toucher. Ce ticket est **public** : n'y indiquez aucune donnée personnelle (joueurs,
téléphones, adresses e-mail). GitHub traite ces informations selon sa propre politique de confidentialité. L'adresse IP de
votre appareil est vue par GitHub lors de l'envoi, comme pour toute connexion Internet. Vous pouvez aussi choisir l'envoi par
e-mail, qui ouvre votre application de messagerie : c'est vous qui relisez puis envoyez.

## Durée de conservation et suppression
Les données restent sur l'appareil jusqu'à leur suppression dans l'application ou jusqu'à la désinstallation
de l'application, qui efface toutes les données. Avant un import, l'application garde dans son dossier privé les trois
dernières copies de vos données (elles disparaissent aussi avec l'application).

## Responsabilité de l'utilisateur
Si vous saisissez des données concernant des joueurs, notamment des mineurs, vous êtes responsable de leur
usage et des autorisations nécessaires (par exemple celles des représentants légaux).
